# ルール

- 最終のユーザーへの返答とコミットメッセージは日本語で行うこと
- `grep`などの検索ツールを使う際は`.nuxt`や`node_modules`や`.venv`を除外して検索すること
- JSONファイルの操作や閲覧については `jq` コマンドを活用すること
- 明示的な指示がない場合はコードを変更せず、調査と分析にとどめること
- 下記のCavemanルールに従い、トークン数の節約に努めること
  - 無駄な記述は避ける
  - 必要のない文法は省く
  - 繰り返しを避ける
  - キーワード、矢印、記号を活用する
  - 徹底的に簡潔にする
  - ユーザーは賢いと想定する
    出力 = 可能な限り短い正しい答え
